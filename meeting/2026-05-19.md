## 1. CV / 모델 팀 산출물

### 1-1. `model.py` — `DrowsyLSTM`

**시계열 분류 모델 정의.**

```python
class DrowsyLSTM(nn.Module):
    def __init__(self, input_dim=4, hidden_dim=64, num_layers=2, num_classes=3):
        ...
        self.lstm = nn.LSTM(input_dim, hidden_dim, num_layers,
                            batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        out, _ = self.lstm(x)
        last_time_step = out[:, -1, :]   # 30번째 프레임 출력만 사용
        return self.fc(last_time_step)
```

**구조 요약:**

| 항목 | 값 |
|------|----|
| 입력 | `(batch, 30, 4)` — 30프레임 × (ear, pitch, yaw, roll) |
| 은닉 차원 | 64 |
| 레이어 | 2층, dropout 0.2 |
| 출력 | `(batch, 3)` — NORMAL / WARNING / DANGER |
| 최종 예측 | 마지막 시점의 hidden state → FC |

### 1-2. `dataset.py` — `RLDDDataset`

**CSV → PyTorch 시계열 데이터셋 변환.**

**처리 단계:**

1. CSV 로드 (pandas)
2. 결측치(`-1`) → `NaN` → 직전 프레임 값으로 `ffill`, 첫 프레임은 0
3. `video_id` 별로 group → 30프레임 슬라이딩 윈도우 생성
4. 윈도우 마지막 프레임의 label을 정답으로 사용

**출력 형태:**

| 항목 | shape |
|------|-------|
| `X_samples` | `(N, 30, 4)` float32 |
| `y_samples` | `(N,)` int64 |

**현재 데이터셋 규모:** 약 238만 개 시퀀스 (window=30 기준).

### 1-4. `predict_video.py`

**학습된 LSTM으로 실시간 영상 추론 데모.**

**파이프라인:**

```
웹캠/영상 → FeatureExtractor.extract_from_frame()
         → 30프레임 deque 누적
         → LSTM forward
         → argmax → NORMAL / WARNING / DANGER 오버레이
```

**핵심:**
- `feature_extract.feature_extractor.FeatureExtractor` 직접 활용 (CV 팀 모듈 그대로)
- `deque(maxlen=30)`로 슬라이딩 윈도우
- 30프레임 채워지기 전까지는 `CALIBRATING...` 표시
- 클래스별 색상: 녹색(정상) / 노랑(주의) / 빨강(위험)

## 4. 파이프라인 설계 산출물

### 4-1. `Dashboard/app.py` ↔ 팀 모듈 연동

대시보드 신규 작성 직후엔 **자체 MediaPipe 호출 + EAR 임계값 규칙**으로 동작하던 독립 코드였음. 팀 모듈(특징 추출, LSTM)을 실제 사용하도록 통합.

**도입 흐름:**

```
웹캠 프레임
   ↓
FeatureExtractor.extract_from_frame()    ← 장원석 모듈
   → (ear, pitch, yaw, roll)
   ↓
30프레임 deque 누적
   ↓
DrowsyLSTM / DrowsyBiLSTM 추론           ← 강영한 모듈
   → softmax 확률 × 가중치 → 0~100 점수
   ↓
5단계 경보 + UI 업데이트
```

**구현 변경점:**

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 얼굴 인식 | `mp.solutions.face_mesh` 직접 | `FeatureExtractor` 호출 |
| EAR 계산 | 자체 `calc_ear()` | 추출기 결과 사용 |
| 졸음 판단 | EAR 임계값 규칙 | **LSTM 추론 → softmax 가중합** |
| 모델 선택 | 없음 | 드롭다운 (lstm / bilstm) |
| 폴백 | 없음 | 모델/30프레임 미충족 시 EAR 규칙 자동 폴백 |

**점수 산출:**
```python
CLASS_SCORE_WEIGHTS = np.array([0.0, 50.0, 100.0])
score = float(np.dot(probs, CLASS_SCORE_WEIGHTS))   # 0~100
```

**모델 캐싱:**
- `@st.cache_resource`로 `load_lstm_model()`, `load_feature_extractor()` 1회만 실행
- 모델 토글 시 30프레임 윈도우 리셋

**선택적 BiLSTM import (원격 호환성):**
```python
try:
    from model import DrowsyBiLSTM
    BILSTM_AVAILABLE = True
except Exception:
    BILSTM_AVAILABLE = False
```
- 모델 코드에 BiLSTM 반영 전이라도 LSTM 단독으로 정상 동작
- BiLSTM 추가 시 드롭다운에 자동 노출
