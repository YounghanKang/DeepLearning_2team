## 1. CV 팀 산출물

### 1-1. `eye_extract/eye_extractor.py`

**구현 클래스**: `EyeExtractor`, `EyeData`

**핵심 기능:**
- MediaPipe Face Mesh로 얼굴 랜드마크 468개 추출
- 그중 양쪽 눈 주변 6개씩 좌표 추출 (`LEFT_EYE_INDICES`, `RIGHT_EYE_INDICES`)
- 눈 영역을 정사각형으로 crop → 흑백 변환 → 64×64 리사이즈
- `EyeData` dataclass로 결과 반환

**랜드마크 인덱스:**
```python
LEFT_EYE_INDICES  = [33, 160, 158, 133, 153, 144]
RIGHT_EYE_INDICES = [362, 385, 387, 263, 373, 380]
```

**출력 데이터 (`EyeData`):**

| 필드 | 타입 | shape | 용도 |
|------|------|-------|------|
| `left_eye_landmarks` | float32 | (6, 2) | EAR 계산 |
| `right_eye_landmarks` | float32 | (6, 2) | EAR 계산 |
| `left_eye_image` | uint8 | (64, 64) | CNN 입력 |
| `right_eye_image` | uint8 | (64, 64) | CNN 입력 |
| `face_detected` | bool | — | 디버깅 |

**처리 세부 사항:**
- 눈 좌표 bounding box에 30% padding 추가 (눈썹·눈가 포함)
- 5×5 픽셀 이하 시 검은 이미지 반환 (안전장치)
- `with EyeExtractor() as ext:` 컨텍스트 매니저 지원
- 얼굴 미검출 시 `None` 반환

**관련 파일:**
- `eye_extract_demo.py` — 웹캠 시각 데모 (`q` 종료, `s` 이미지 저장)
- `EYE_EXTRACT_README.md` — 모듈 사용 가이드

### 1-2. `ear/ear.py`

**구현 함수/클래스**: `calculate_ear()`, `EARCalculator`, `EARResult`

**EAR 공식 구현:**
```python
EAR = (||p2-p6|| + ||p3-p5||) / (2 * ||p1-p4||)
```
- 분자: 세로 거리 합
- 분모: 가로 거리 × 2
- C < 1e-6 시 0.0 반환 (0 나눗셈 방지)

**`EARCalculator` 클래스 핵심 기능:**

1. **양쪽 눈 EAR 계산** — 좌·우 분리 보고 (`ear_left`, `ear_right`) + 평균 (`ear_avg`)

2. **개인별 baseline 자동 측정**
   - `start_calibration()` → 5초간 정면 응시
   - `finish_calibration()` → 상위 75% 평균으로 baseline 계산
   - 임계값 = baseline × 0.7 (기본)
   - 최소 30 샘플 필요

3. **이동평균으로 떨림 제거**
   - `deque(maxlen=5)` — 최근 5프레임 평균
   - 30fps에서 약 167ms 윈도우

4. **눈 감김 판정**
   - `ear_smoothed < threshold` → `is_closed = True`

**`EARResult` 필드:**

| 필드 | 타입 | 의미 |
|------|------|------|
| `ear_left`, `ear_right` | float | 좌우 EAR |
| `ear_avg` | float | 양쪽 평균 (원본) |
| `ear_smoothed` | float | 이동평균 적용값 |
| **`is_closed`** | bool | **눈 감김 여부 (PERCLOS 입력)** |
| `threshold` | float | 현재 임계값 |

**관련 파일:**
- `demo_ear.py` — eye_extractor 통합 데모 (`c` 보정, `q` 종료)
- `test_ear.py`, `test_eye_extractor.py` — 자동 테스트
- `EAR_README.md` — 모듈 사용 가이드

### 1-3. `head_pose/head_pose.py`

**구현 클래스**: `HeadPoseEstimator`, `HeadPoseResult`

**원리:**
1. MediaPipe Face Mesh로 6개 랜드마크 2D 좌표 추출 (코끝, 턱, 양쪽 눈가, 양쪽 입꼬리)
2. 표준 3D 얼굴 모델(`FACE_3D_MODEL`)과 매칭
3. OpenCV `solvePnP`로 회전 벡터 추정
4. `cv2.Rodrigues` + `decomposeProjectionMatrix`로 오일러 각도 변환

**사용 랜드마크:**
```python
LANDMARK_INDICES = {
    "nose_tip":    1,
    "chin":        152,
    "left_eye":    263,
    "right_eye":   33,
    "left_mouth":  287,
    "right_mouth": 57,
}
```

**`HeadPoseResult` 필드:**

| 필드 | 타입 | 의미 | 졸음 신호 |
|------|------|------|----------|
| `pitch` | float | 위아래 (degree) | **+ 값 = 고개 떨굼 → 위험** |
| `yaw` | float | 좌우 회전 (degree) | 큰 값 = 한눈팔이 |
| `roll` | float | 좌우 기울임 (degree) | 큰 값 = 비스듬한 자세 |
| `confidence` | float | 추정 신뢰도 (0~1) | 낮으면 필터링 권장 |
| `face_detected` | bool | 검출 여부 | — |

**구현 세부:**
- pitch 정규화: ±180 → ±90 변환 (직관성)
- pitch 부호 보정: 고개 떨굼 = + 값
- 카메라 보정값 없이 근사 (focal length = width)
- 신뢰도 계산: yaw·pitch 절대값에 반비례
  - yaw 60도 이상에서 0
  - pitch 90도 이상에서 0

**관련 파일:**
- `demo_head_pose.py` — 3축 시각화 + `HEAD DOWN` 경고 (pitch ≥ 20도)
- `test_head_pose.py` — 자동 테스트 (M1 기준 10ms/프레임)
- `READ_ME` — 사용 가이드

## 3. 파이프라인 설계 산출물

### 3-1. `PIPELINE.md`

**전체 아키텍처 + 모듈 인터페이스 명세 문서.**

**문서 구성 (9개 섹션):**

1. 전체 아키텍처 — 배치/실시간 두 흐름 다이어그램
2. 두 가지 처리 흐름 — 학습(영상→CSV→모델) / 추론(웹캠→경보)
3. 모듈 현황 매트릭스
4. 모듈별 인터페이스 명세 (입출력 타입, 클래스 시그니처)
5. 신호 융합 전략 — EAR + CNN + Head Pose 결합 방법
6. 에러 처리 규칙 — 얼굴 미검출, 신뢰도 부족 등
7. 성능 및 스레딩 — MediaPipe 중복 호출 분석, 스레드 분리 구조
8. 폴더 구조
9. 개발 로드맵

**신호 융합 전략 정의:**

```python
# 눈 감김 신호: CNN 우선, 미완성 시 EAR fallback
def fuse_eye(ear_closed, cnn_closed, cnn_available):
    return cnn_closed if cnn_available else ear_closed

# 고개 떨굼 신호: pitch >= 20도 + confidence >= 0.5
def fuse_head(head_result):
    if head_result.confidence < 0.5: return False
    return head_result.pitch >= 20.0

# 최종 상태: 두 PERCLOS 중 큰 값 기준
def decide_state(p_eye, p_head):
    combined = max(p_eye, p_head)
    if combined >= 0.30: return 'DANGER'
    if combined >= 0.10: return 'WARNING'
    return 'NORMAL'
```

**에러 처리 규칙:**

| 상황 | 처리 |
|------|------|
| 얼굴 미검출 | 프레임 스킵, 5초 지속 시 PERCLOS 리셋 |
| Head pose confidence < 0.5 | 해당 신호 무시 |
| EAR 좌표 비정상 | ear=0.0 반환 |
| 웹캠 끊김 | 루프 종료, 자원 해제 |

**성능 분석:**

| 모듈 | 1 프레임당 |
|------|-----------|
| MediaPipe Face Mesh | 10~15ms |
| EAR 계산 | < 1ms |
| Head Pose (solvePnP) | 2~3ms |
| **합계** | **약 28~50 FPS** |
